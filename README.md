# 🤖 Codex PR Healer

An autonomous agentic coding tool designed to automatically detect, diagnose, and heal broken Pull Requests and failing builds. Powered by Next.js and AI-driven repair loops.

---

## 🚀 Features

* **Autonomous Fixes:** Analyzes build logs and stack traces to identify root causes.
* **Agentic Repair Loop:** Iteratively tests and verifies proposed code patches before applying.
* **Seamless Integration:** Built to work alongside modern CI/CD pipelines and GitHub workflows.
* **Modern Tech Stack:** Fast, responsive Next.js frontend with unified API routes.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router, Turbopack)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **LLM / AI Engine:** OpenAI / OpenRouter API
* **Deployment:** Vercel
